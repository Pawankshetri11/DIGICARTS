DIGICARTS THEME 1.2.0

An original classic WordPress theme for digital products, using native WooCommerce templates and hooks.

EDIT YOUR SITE
Appearance > Customize > DIGICARTS homepage: edit the hero heading, highlighted text, description and eyebrow.
Header & Footer: customize the site header and footer using the separate DIGICARTS Header & Footer plugin.
Appearance > Menus: assign main, utility, information, quick links and bottom footer navigation.
Products > Add new: create products, upload preview images and set prices.
For digital files, enable Virtual and Downloadable and configure the files and license details.
Published visible products automatically appear in the homepage Fresh Finds section.
Collection illustrations are design previews, not items for sale.

COLLECTIONS
Website templates (website-templates), Design assets (design-assets), E-books & guides (ebooks-guides), Productivity (productivity).
The local setup includes these WooCommerce categories. On another site, create matching category slugs.

INSTALL ELSEWHERE
Install and activate WooCommerce and create its Shop, Cart, Checkout and My Account pages.
Upload digicarts-theme.zip under Appearance > Themes > Add new > Upload Theme.
Upload and activate digicarts-header-footer.zip under Plugins > Add New > Upload Plugin.
Save permalinks under Settings > Permalinks and create the four category slugs listed above.
The front-page template works with either a static front page or the default homepage setting.

FEATURES
Responsive homepage, product/category/search pages, native product variations, Cart and Checkout blocks, account/downloads, FAQs, journal, 404, reduced-motion and keyboard navigation support.
The separate header/footer plugin provides navigation, product search, live cart display, footer and newsletter settings.
No page builder, remote fonts, or premium theme dependency.
Original collection illustrations use HTML/CSS; edit template-parts/artwork.php and style.css to change them.

REMAINING STORE SETUP
Upload actual products and downloadable files. Configure payment providers and email delivery. Add actual policies and support details before public launch.
No tests or browser checks were run for the header/footer migration, at the user's request.

Typography uses Poppins, served locally by the DIGICARTS Header & Footer plugin.
